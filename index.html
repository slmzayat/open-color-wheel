Open Color Wheel

Open Color Wheel rebuilds the Open Color palette in OKLCH to unify perceptual lightness across hues. Step 600 holds the same lightness in red as in teal, within 0.012 OKLCH, across 17 chromatic hues and 5 temperature-adjusted gray families.

A build script parses a single specification file, calculates all color values, and evaluates contrast against WCAG standards. The build fails CI immediately if any 4.5:1 contrast pairing drops below threshold.
